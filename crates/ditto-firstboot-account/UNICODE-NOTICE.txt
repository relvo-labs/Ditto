版本：Unicode 17.0.0（固定 release data；不是浮動分支）
SHA-256：2e1efc1dcb59c575eedf5ccae60f95229f706ee6d031835247d843c11d96470c
採用方式：只選 General_Category Cf、Zl、Zp 的 172 個 code points，合併為
21 個相鄰範圍，寫入 src/input.rs 的 display_format_or_separator。
沒有複製上游執行程式碼，也不修改原始分類；原生 Rust 判定供固定可信 helper 使用。
更新時須以固定 Unicode release 重新選取與合併，更新版本、雜湊、授權及分類測試。
測試：display_name_rejects_format_and_line_paragraph_categories；另以固定來源
逐一比對所有 Unicode scalar，結果記於 task 的 repair-unicode-check.log。
