# Ditto — 對話驅動的可組合桌面前端原型

以柔光果凍預設桌面為基礎，驗證對話改造、可見差異、試看、保留與撤銷的完整使用流程。

## 體驗

點擊大型 Ditto，或按 Ctrl/Cmd+J。試說：

- 幫我做開發桌面，保留原本配色
- 把 Dock 放左邊，換成薄荷綠
- 做一個叫「我的下一步」的待辦面板
- 做一個專案進度面板
- 隱藏 Ditto 角色
- 保存為我的桌面
- 撤銷上一步

組合中心提供預設與自訂配置、匯入匯出；模組中心支援啟停及依賴提示。筆記、待辦、專注計時器、視窗移動縮放、四個工作區與應用搜尋可操作。歷史支援逐步撤銷，關於面板可啟動失敗回復演練。

## 邊界

本機意圖解析示範，未連接 LLM、Cordis 或 Linux。模板產生的是可互動 UI 實例，不是 AI 生成任意程式碼。終端、系統狀態與檔案為示範。配置、對話、待辦、筆記只保存在此瀏覽器；無後端、無憑證、無外部資料傳送。

## 開發

- pnpm install
- pnpm dev
- pnpm test
- pnpm build

原始碼在 src/；生成的角色素材在 public/；Vite 產生可獨立部署的 dist/。不需要後端。正式原生技術仍為 Qt Quick＋Quickshell，前端契約與移植接點見 [研究與互動決策](../../docs/research/RESEARCH-AND-INTERACTION.md)。

研究與產品決策、來源、可驗證邊界均記錄於儲存庫根目錄的 docs/。

開發需求：Node.js 22 或以上、pnpm 10.11.0。從此目錄執行上述命令；本機網址以 Vite 輸出為準。

角色圖片為既有生成素材；PNG 與臉部／動畫由前端共同呈現。正式發行的名稱、角色及素材權利仍依 PRD 審查，未在本次匯入新增開源授權。
