# D-01a 參考瀏覽器更新為 Firefox 156.0.1

| 欄位 | 內容 |
| --- | --- |
| 決策日期 | 2026-09-26 |
| 狀態 | 已決定；修訂 [D-01](2026-09-22-d01-reference-platform.md) 的參考應用版本 |
| 決策者 | 使用者（參考機 owner）＋平台工程 |

## 結論

參考瀏覽器由 Firefox snap `156.0-1` rev 8929 改為 `156.0.1-1` rev 8969。參考夾具啟動 Firefox 時設定 `MOZ_DISABLE_WAYLAND_PROXY=1`。

## 依據

- 2026-09-26 18:30（CST）snapd 自動更新 Firefox；同日 preflight 以 `firefox drifted` 拒絕量測，EX-01／EX-03 因 Firefox 未映射視窗而失敗。
- 使用者於 2026-09-26 明確表示參考機可以使用新版，不退回 rev 8929。
- 在 headless Wayfire 夾具中，rev 8969 預設經由 Firefox 內建的 Wayland proxy 連線，20 秒內沒有映射任何 toplevel；同一合成器上 foot 可正常映射。設定 `MOZ_DISABLE_WAYLAND_PROXY=1` 後，Firefox 直接連線並映射為 `firefox_firefox`。

## 考慮過但沒選的方案

- **退回 rev 8929 並 hold**：可保留原指紋，但使用者選擇採用新版。
- **沿用 proxy、延長等待時間**：proxy 在 40 秒內都沒有連上合成器，延長等待不能解決問題，也會拉長每晚的 runner 時間。

## 影響

- `reference-machine.lock.json`、支援矩陣、參考映像 README 與量測條件改為新版本。
- 依 D-01，指紋改變後舊的 EX-01／03／04 結果不能與新版本的量測續接；這三項須以新指紋重跑，EX-09 的三晚計數也從新指紋起算。
- snap 仍會自動更新。參考機 owner 應執行 `sudo snap refresh --hold firefox`，否則下一次更新會再次造成 preflight 漂移。
