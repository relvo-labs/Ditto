# G0 資源量測固定變因

這是 G0-QA-01 的量測準備清單，**不是已執行的實體機紀錄**。每次 run 在 `conditions.json` 填寫實際值，並以同一份 `manifest.json` 的單元集合採樣。

| 變因 | G0 應固定並記錄的值 |
| --- | --- |
| 參考機 | 發行版、核心、CPU、RAM、SSD、GPU、驅動、1080p／60 Hz 顯示器 |
| 桌面元件 | Core、Shell、合成器的單元與版本；G0 沒有 Cordis 宿主 |
| 背景 | 來源、解析度、縮放與靜態／動態狀態 |
| 角色素材 | 來源、解析度、待命狀態；另測角色關閉、減少動畫 |
| 參考應用 | 瀏覽器、終端、編輯器的版本、視窗數與開啟內容 |
| 其他資料 | 插件資料集與索引：G0 不適用；對話長度：G0 無 Agent |
| 採樣流程 | 每次冷登入；暖機 300 秒；採樣 600 秒；建議間隔 5 秒；三次重複 |
| 排除清單 | 明列每個排除單元與原因；不得排除 Ditto 背景服務、Shell、Core 或合成器 |

效能與資源結果只在凍結的實體參考機有效。開發 VM 試跑可用來檢查工具格式，但不得成為 EX-05 的基線。
