UnicodeClasses.js: Unicode 17.0.0 property data

Generated by tests/firstboot/generate_unicode.py from the installed ICU 78
Unicode 17.0.0 data, using u_hasBinaryProperty (Lowercase, Uppercase, Alphabetic)
and u_charType (Number, Cc/Cf/Zl/Zp). No upstream executable source was copied or
modified. The generated ranges preserve the properties; the binary-search
consumer is Ditto code. ICU is used only at generation time, not as a new runtime
service/dependency. Source release: https://icu.unicode.org/download/78
Data definition: https://www.unicode.org/Public/17.0.0/ucd/
Update only together with the helper's Rust Unicode version; the generator
refuses any Unicode version other than 17.0.0. Tests cover the shared protocol
cases, astral scalar counts, UTF-8 bounds and format/control rejection.
