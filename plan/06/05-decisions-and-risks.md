## 2. 風險

| 風險 | 處理 |
| --- | --- |
| VM 證據被延伸成 G4 出口 | 證據環境表（[03 §1](03-verification-and-measurement.md#1-證據環境)）；評審逐項標類別 |
| 量測未達標時被悄悄改範圍 | 原則 5；調整須核定並留紀錄 |
| 幀時 NFR-05 長期未達 95% | 先分析 G0 兩次交叉量測的條件差異，再決定修正或提案 |
| 授權不相容在發行前才發現 | 新增會散布的依賴時就更新盤點（`ditto-release-audit` 第 3 步） |
| 參考機同時是開發機 | 量測前確認沒有競爭工作；座位測試先徵求 owner 同意 |
| 硬體或測試者遲遲沒有到位 | 對應 issue 保持阻擋並列入已知限制，不以替代證據結案 |
| 並行 PR 寫到同一檔案 | [04 §3](04-workplan.md#3-寫入範圍與共用檔案) 指定單一寫入者 |
| 安裝包與參考機私有前綴分歧 | 以安裝包重建參考機並通過 preflight，作為第二人重建證據 |
