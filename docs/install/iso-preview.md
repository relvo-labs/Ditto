# 安裝 Ditto 預覽版（ISO）

> **目前狀態：這份說明描述的安裝方式尚未建出、也尚未在虛擬機或實體機上驗證。** 安裝程式的原始碼已完成，ISO 要等建置與驗收（#221）通過、owner 確認後，才會以 GitHub pre-release「預覽版」發佈。在那之前，請不要依這份說明安裝到存有重要資料的電腦。

預覽版會**清除整顆磁碟**再安裝 Ditto，不保留任何既有的系統或檔案，也不提供雙系統。

## 需要準備

- 一台 **UEFI、x86_64（64 位元 Intel／AMD）** 的電腦。不支援舊式 BIOS 開機，也不支援 ARM。
- 在韌體設定中**關閉 Secure Boot**。預覽版沒有簽章，Secure Boot 開啟時無法開機。
- 一顆**內建磁碟**當安裝目標，容量至少約 26.6 GB（十進位，依目前映像的分割區大小計算；實際下限以安裝畫面為準）。容量越大，多出的空間都會給系統與你的檔案使用。
  - 隨身碟、SD 卡等可移除裝置、唯讀磁碟、4K 原生磁區的磁碟不會出現在可選清單中。
  - 這顆磁碟上的**全部資料都會被清除**，請先備份。
- 一支 USB 隨身碟，用來製作安裝媒體（容量需大於 ISO 檔）。製作時隨身碟上的資料也會被清除。
- 顯示卡：使用開源驅動（Intel、AMD、NVIDIA 的 nouveau）。**不含 NVIDIA 專有驅動。** 沒有可用的顯示裝置時，安裝程式會改用英文文字畫面。
- 記憶體：安裝程式整個在記憶體中執行；需要多少記憶體尚未量測。

## 下載與核對

從 GitHub Releases 的預覽版下載 `ditto-<版本>-installer-x86_64.iso` 與 `SHA256SUMS`，在同一個資料夾執行：

```sh
sha256sum -c SHA256SUMS
```

看到 `OK` 才繼續。ISO 內的安裝程式也會在寫入前核對隨附的系統映像；那是防止媒體損毀的檢查，**不是簽章**，是否為官方發佈仍以這一步核對 GitHub 上的 `SHA256SUMS` 為準。

## 製作安裝隨身碟

在 Linux 上，先用 `lsblk` 確認隨身碟的裝置名稱（例如 `/dev/sdX`），**確定不是你的系統磁碟**後執行：

```sh
sudo dd if=ditto-<版本>-installer-x86_64.iso of=/dev/sdX bs=4M conv=fsync status=progress
```

也可以使用能「以原始映像（dd 模式）寫入」的工具。不要把 ISO 當成一般檔案複製到隨身碟。

## 安裝步驟

1. 插入隨身碟，從 UEFI 開機選單選擇它開機（Secure Boot 須已關閉）。
2. 安裝程式會先尋找安裝媒體，接著列出這台電腦的磁碟：型號、容量與序號。不能使用的磁碟會列在下方並寫明原因，例如「這是安裝用的隨身碟或光碟」。
3. 選擇要安裝的磁碟。下一個畫面會再顯示一次型號、容量、序號，以及「將清除整顆磁碟的全部資料」。預設選項是「取消」；確定後再按「清除並安裝」。
   - 文字畫面中，需要輸入 `ERASE` 才會開始；只按 Enter 會取消。
4. 安裝程式會依序核對安裝資料、清除舊的分割表、寫入、讀回核對，最後寫入新的分割表。畫面會顯示目前步驟與百分比。
5. 看到「安裝完成，內容已逐一讀回核對」後，**拔除隨身碟**，再按「已拔除，重新開機」。
6. 第一次從磁碟開機時，會出現建立帳號的畫面：設定名字、帳號與密碼後，用剛設定的密碼登入 Ditto 桌面。系統沒有預設帳號，也不會自動登入。

第一次開機時，系統會自動把磁碟剩餘空間擴充給系統狀態分割區，不需要另外操作。

## 取消與失敗

- 在確認畫面按「取消」，或在開始寫入之前取消，**磁碟不會被更動**。
- 寫入開始後取消、或寫入／讀回失敗時，磁碟原有的資料已被部分清除，**這顆磁碟會無法開機**。重新執行安裝即可，或改用其他磁碟。
- 安裝資料核對不符時，安裝程式會在寫入前停止，並請你重新下載 ISO、核對 SHA256。
- 只有全部寫入並讀回核對成功，才會顯示「安裝完成」。如果安裝服務中途停止，畫面會說明「無法確認結果」，請不要從那顆磁碟開機，重新安裝一次。

## 會清除什麼

所選磁碟的分割表與全部內容都會被取代，原有的作業系統與檔案都將無法再由系統存取。這不是安全抹除：沒有被新內容覆蓋的區域可能仍殘留舊資料。如果磁碟要轉手，請另外做安全抹除。

## 已知限制

- 只支援 UEFI x86_64；需要關閉 Secure Boot（沒有簽章）。
- 不支援磁碟加密（LUKS）、雙系統或保留既有分割區。
- 不含 NVIDIA 專有驅動；不支援的顯示硬體只能使用英文文字安裝畫面。
- 不能安裝到 USB 隨身碟等可移除裝置，也不支援 4K 原生磁區的磁碟。
- ISO 內的完整性核對不是簽章；官方來源請以 GitHub 上的 `SHA256SUMS` 核對。
- 清除不是安全抹除。
- 每次安裝的檔案系統 UUID 都相同（分割表的識別碼則每次隨機產生）。
- 安裝畫面與首次設定的螢幕閱讀器（Orca）完整流程尚未驗證；安裝環境不含 Orca。
- 文字安裝畫面只有英文。
- 安裝程式需要的記憶體、光碟（非隨身碟）開機的相容性，以及實體顯示卡支援，都尚未驗證。
- 尚無系統更新與回退通道；預覽版之後的更新方式另行公告。
